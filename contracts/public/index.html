Taniin GitHub

Bertani pixel, panen tercatat di blockchain

Tanam, panen, dan jual hasil kebun bersama pemain lain dan Pak Tani AI. Gratis di browser dan Android, tanpa harus punya wallet duluan.

Main di browser Unduh APK Android

APK untuk Android 8.0 ke atas. Langsung main sebagai tamu, masuk kapan saja.

Yang bisa kamu lakukan

  • Bertani dari nol

    Beli benih kentang, bawang, stroberi, dan bit. Tanam di lahanmu, tunggu matang, panen, lalu jual ke pengepul.

  • Main bareng

    Lihat petani lain bergerak di peta yang sama, ngobrol di chat, dan minta Pak Tani AI menanam atau memanen untukmu.

  • Naik level

    Selesaikan quest harian untuk XP, buka achievement, dan pakai baju petani baru yang bisa dilihat pemain lain.

  • Hadiah on-chain

    Masuk dengan email atau Google lewat Privy. Lahan jadi NFT, panen jadi item, dan Game Coin bisa ditukar ke token TANI atau ETH Sepolia.

Cuplikan

Cara kerja Web3-nya

  1. Main sebagai tamu. Progres tersimpan di perangkatmu, tanpa daftar apa pun.
  2. Masuk dengan Privy. Wallet Sepolia dibuat otomatis dari email atau Google, dan progres tamu ikut dibawa.
  3. Server memeriksa tiap aksi. Harga, waktu tumbuh, dan stok dicek di server sebelum transaksi dikirim, jadi ekonominya tidak bisa diakali dari aplikasi.
  4. Tercatat di Sepolia. Lahan (ERC-721), benih dan panen (ERC-1155), dan token TANI (ERC-20). Setiap transaksi bisa dibuka di Etherscan.

Taniin berjalan di testnet Sepolia. Token dan ETH di dalamnya tidak punya nilai uang sungguhan.
